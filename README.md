# 🏫 校園快速表單與報名收據系統 (GAS Quick Form)

以 **Google Apps Script (GAS)** 綁定 Google 試算表打造的「全校性快速報名、分班統計、導師自動寄信與收據批次列印系統」。  
無需外部伺服器，直接透過 Google 試算表後台設定題目與開放時間，並發布為 Web App 供學生以「學號」進行身分驗證與線上報名。

---

## ✨ 核心功能特色

1. **學號身分驗證與資料預帶**
   - 學生於前台輸入學號後，自動比對 `原始名單` 帶出班級、座號與姓名。
   - **重複報名檢視與覆蓋更新**：若學生已報名過，系統會提示上次報名時間並自動載入原填寫內容，修改後可直接更新覆蓋原有紀錄，避免重複登記。
2. **視覺化後台題目管理 (`Admin.html`)**
   - 在試算表內直接開啟管理視窗，設定活動說明、開放時間與截止時間。
   - 支援題目卡片新增、刪除與上下排序，儲存後自動同步更新 `表單回復` 與所有班級分頁表頭。
3. **支援金額與折扣即時試算**
   - 前端提供「目前預估總金額」即時計算與送出前確認頁面。
   - 支援 `單選(金額)`、`多選(金額)` 與連動前一題的 `單選(折扣)` 題型。
4. **自動分班建表與合計公式**
   - 依 `原始名單` 自動為每個班級建立獨立分頁（含 `A1` 列印標題與第 2 列表頭）。
   - 學生送出表單後同步寫入 `表單回復` 總表與對應的班級分頁；若表頭含「總計」或「金額」，底部「合計」列會自動產生 `=SUM(...)` 加總公式。
5. **一鍵匯出各班統計並 Email 通知導師**
   - 自動檢查各班報名狀況：僅針對「已有學生報名」的班級建立獨立 Google 試算表副本、開放檢視權限給導師，並透過 `MailApp` 自動寄送統計表連結（無人報名的班級自動跳過）。
6. **班級收據批次列印 (`ReceiptDialog.html`)**
   - 支援選擇單一班級或全校所有班級 (`ALL`)，依班級與座號自動排序產生標楷體收據卡片。
   - 可自訂收費項目名稱，搭配瀏覽器列印（`@media print`）或存為 PDF，並自動隱藏控制列與加上裁切虛線。

   ├── 5. 匯出各班獨立試算表並寄信給導師 (exportAndEmailSheets)

## 📊 試算表分頁規格說明

本系統為 **Container-bound Script（綁定試算表的 Apps Script）**，試算表內會使用以下分頁（亦可透過選單「`📖 建立/更新『使用說明』分頁`」在試算表內自動生成說明頁）：

### 1. `原始名單`（需手動建立並貼入資料）
| 欄位位置 | 欄位要求 | 說明 |
| --- | --- | --- |
| **第 1 列** | `A` 欄：`班級`<br>`B` 欄起：`座號`、`學號`、`姓名`... | `B` 欄起的欄位名稱會自動帶入各班分頁作為學生基本資料欄位。 |
| **第 2 列起** | 學生資料列 | **重要**：`A` 欄須為班級名稱，**`C` 欄必須為「學號」**（供學生端登入驗證與寫回比對）。 |

### 2. `導師名單`（需手動建立並貼入資料）
| 欄位位置 | 欄位要求 | 說明 |
| --- | --- | --- |
| **第 1 列** | `A` 欄：`班級` \| `B` 欄：`導師` \| `C` 欄：`Email` | 固定表頭格式，請勿更動欄序。 |
| **第 2 列起** | 各班導師資訊 | 執行「匯出班級試算表並寄信給導師」時讀取此表。 |

### 3. `表單回復`（系統自動建立與維護）
* **`A1`**：活動說明文字
* **`A2`**：報名開放時間（`Date`）
* **`A3`**：報名截止時間（`Date`）
* **`F1:3` 起**：題目設定（第 1 列題目名稱、第 2 列題型、第 3 列逗號分隔選項）
* **第 4 列**：總表頭（`班級`、`座號`、`學號`、`姓名`、`時間` + 各題目名稱）
* **第 5 列起**：學生線上報名紀錄

### 4. `各班級分頁`（例如 `101`、`102`...，由系統自動生成）
* **`A1`**：`{班級}班 報名統計表`
* **第 2 列**：`[原始名單 B 欄起基本資料] + 時間 + [各題目]`
* **第 3 列起**：各班學生名單與即時填入的報名資料
* **最末列（合計）**：欄位名稱包含「總計」或「金額」時，自動建立 `=SUM(...)` 加總公式

## 📝 支援題型與計費語法 (`Admin.html`)

在「`2. 設定題目與活動時間`」視窗中，支援以下 8 種題型：

| 題型名稱 | 選項格式說明 | 前台行為與計價邏輯 |
| --- | --- | --- |
| `簡答` | 不需選項 | 單行文字輸入（前台預設必填） |
| `段落` | 不需選項 | 多行文字輸入 |
| `單選` | 以英文逗號分隔，如 `葷食, 素食` | 單選圓鈕（預設選取第一項） |
| `多選` | 以英文逗號分隔，如 `項目A, 項目B` | 多選核取方塊 |
| `單選(金額)` | 選項需含 `(金額)`，如 `排骨飯(100), 雞腿飯(110)` | 自動擷取括號內數字加總至預估金額 |
| `單選(折扣)` | 選項需含 `(百分比%)`，如 `8折(80%), 原價(100%)` | **自動對前一題 `單選(金額)` 套用折扣百分比** |
| `多選(金額)` | 選項需含 `(金額)`，如 `加購飲料(20), 加購水果(30)` | 勾選項目之括號內數字累加至預估金額 |
| `總計` | 不需選項 | 作為試算表加總欄位保留（前台不顯示輸入框） |

> 💡 **收據金額欄位識別**：批次列印收據時，系統會自動搜尋 `表單回復` 第 4 列表頭中第一個包含「`金額`」、「`總計`」、「`費用`」或「`小計`」的欄位作為收據金額。

## 🚀 快速部署與使用步驟

### 方式 A：使用 Clasp CLI 同步程式碼（推薦）

1. 安裝並登入 [`@google/clasp`](https://github.com/google/clasp)：
   ```bash
   npm install -g @google/clasp
   clasp login
   ```
   *(請確認已於 [Google Apps Script 設定頁](https://script.google.com/home/usersettings) 開啟 Google Apps Script API)*

2. 若要部署到**新的**試算表專案：
   - 建立一份新的 Google 試算表，點選上方選單「擴充功能」→「Apps Script」，從專案設定取得新的 `Script ID`。
   - 修改本目錄 `.clasp.json` 中的 `"scriptId"` 為您的專案 ID。
   - 執行推送：
     ```bash
     clasp push
     ```

### 方式 B：手動複製貼上至 Google Apps Script

1. 開啟目標 Google 試算表，點選上方選單「**擴充功能**」→「**Apps Script**」。
2. 將 `程式碼.js` 的內容貼入預設的程式檔案中。
3. 新增三個 HTML 檔案，檔名分別為 `Index`、`Admin`、`ReceiptDialog`，並貼入對應的 `.html` 內容。
4. 於左側「專案設定」勾選「在編輯器中顯示『appsscript.json』資訊清單檔案」，貼入 `appsscript.json` 內容並儲存。

### 上線操作流程（試算表內 `🚀 自動化工具` 選單）

重新整理試算表後，上方選單列會出現 **`🚀 自動化工具`**，依序操作即可：

1. **步驟 0**：若為舊活動延續，可執行 `0. 一鍵清空，開始新的報名` 清除舊班級分頁與報名紀錄。
2. **步驟 1**：建立並填妥 `原始名單` 與 `導師名單` 分頁。
3. **步驟 2**：執行 `2. 設定題目與活動時間`，於彈出視窗設定活動說明、起訖時間與題目並儲存。
4. **步驟 3**：執行 `3. 依原始名單建立班級分頁`（儲存步驟 2 設定時亦會自動觸發同步）。
5. **步驟 4**：至 Apps Script 編輯器右上角點選「**部署**」→「**新增部署**」→ 類型選擇「**網頁應用程式**」：
   - **執行身分**：`我` (`USER_DEPLOYING`)
   - **誰可以存取**：`所有人` (`ANYONE_ANONYMOUS`) 或貴校網域內使用者
   - 複製產生的 Web App URL 發送給學生填報。
6. **步驟 5**：報名結束後，執行 `5. 匯出班級試算表並寄信給導師`，一鍵分發各班統計表。
7. **步驟 6**：執行 `6. 🧾 班級收據批次列印`，選擇班級與收費項目名稱後即可列印或另存 PDF。

## ⚙️ 技術規格 (`appsscript.json`)

* **執行環境**：Apps Script `V8` Runtime
* **時區設定**：`Asia/Taipei` (`GMT+8`)
* **Web App 預設權限**：`executeAs: USER_DEPLOYING`、`access: ANYONE_ANONYMOUS`
